③ The code: GitHub and every file in plain words

Open the repository on GitHub ↗

FileWhat it does
run.pyThe start button. One command starts every part of the engine.open ↗
engine/config.pyThe settings card: which coin, which mode, where the database file lives. Keys come from .env, never from the code.open ↗
engine/sources.pyThe ears. Listens to Binance Testnet (LIVE) or plays a recorded file (REPLAY) and drops each message on a conveyor belt.open ↗
engine/clean.pyThe cleaner. Turns Binance's short, messy notes ("p", "q") into one tidy row with proper numbers and time.open ↗
engine/pipeline.pyThe clerk at the end of the belt: take a message, clean it, store it, repeat forever.open ↗
engine/store.pyThe notebook. Saves every clean deal and every order in one SQLite file on the laptop.open ↗
engine/signals.pyThe advisor. Compares a short average with a long average and says BUY, SELL or HOLD. A human still decides.open ↗
engine/exchange.pyThe post office. Signs an order with the secret key (HMAC) and sends it to Binance Testnet, or to a pretend exchange in demo mode.open ↗
engine/api.pyThe front desk. A FastAPI menu (/prices, /signal, /orders, /trace …) that the dashboard and other teams call.open ↗
engine/trace.pyThe black screen. Writes one line for every call in and out, so you can watch the engine work.open ↗
dashboard/index.htmlThe page layout: chart, advice, order form, tables, call trace.open ↗
dashboard/app.jsThe page's brain. Asks the API every few seconds and draws the answers; shows each call as a curl line.open ↗
dashboard/style.cssThe page's look: colours, light and dark mode, the black terminal box.open ↗
tools/make_replay_file.pyMakes the pretend (MOCK) price recording used for demos and tests, so nothing needs the internet.open ↗
tools/make_snapshot.pyFreezes the dashboard's answers into snapshot.json so the website works without a running engine.open ↗
tests/Checks that each part still works. Run: python -m pytest -qopen ↗
plugin/openapi.jsonThe printed menu other teams build against (the API contract).open ↗

Run it in three commands

pip install -r requirements.txt
python run.py   # REPLAY: MOCK data, no keys
# open localhost:8000  and  localhost:8000/docs

LIVE on Testnet: copy .env.example to .env, paste your Testnet keys, run python run.py --live.

Honest notes (say these in the viva)

  • Testnet prices are practice prices, not the real Binance market.
  • The signal is advice only. The engine never places an order by itself.
  • Next-minute direction is close to a coin toss: the dashboard shows the rule's accuracy next to the "always guess the commonest" baseline, scored on later minutes only.
  • Prices in data/replay/ and in the snapshot are MOCK.
